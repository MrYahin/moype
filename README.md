# moype

Прототип мультиагентной системы планирования производства на Java, Spring Boot и JADE.

## Назначение

Проект исследует организацию производственного планирования через взаимодействие программных агентов. Заказы, подразделения, группы ресурсов и производственные этапы представлены отдельными типами агентов. Событийный механизм связывает запуск заказов с обработкой в агентной среде.

## Основные возможности

- Работа с производственными заказами, ресурсами и этапами через прикладные сервисы и веб-контроллеры.
- Запуск агентов подразделений и регистрация событий начала планирования заказов.
- Координация событий отдельным агентом-менеджером.
- Расчёт критического пути заказа через выделенный агент и сервис CriticalPath.
- Хранение данных с использованием JPA и MySQL.
- Веб-интерфейс; классы для интеграции с 1С через веб-сервисы.

Наличие компонентов в исходном коде не означает, что все сценарии проверены в работающей среде.

## Архитектура

Основные слои приложения:

- controllers — веб-контроллеры заказов, ресурсов, этапов и диспетчеризации.
- service — прикладная логика и запуск планирования.
- agents — агенты JADE и их поведения.
- dbService — слой доступа к данным.
- model — модели предметной области.

Агентный слой включает DivisionAgent, ResGroupAgent, OrderProductionAgent, StageAgent, EventAgent, EventManagerAgent и OrderCriticalPathAgent.

При запуске планирования CompanyService получает предприятия и подразделения из базы данных, запускает агентов подразделений с mode == 1, регистрирует события startOrder для заказов и запускает EventsManager.

## Технологический стек

- Java 8.
- Spring Boot 1.5.3.RELEASE.
- JADE 4.5.0 и jade4spring 1.1.
- Spring Web, Spring Data JPA, Spring Security и Spring Web Services.
- MySQL Connector/J 8.0.13.
- Maven, упаковка WAR.
- JAXB для генерации моделей из XML-схем.

## Структура репозитория

```text
src/main/java/ru/moype/  — серверная логика и агенты
src/main/resources/     — конфигурация и ресурсы
src/main/webapp/         — веб-интерфейс
src/main/xsd/            — XML-схемы
src/main/generate/       — каталог генерации JAXB
lib/                    — локальный Maven-репозиторий зависимостей
pom.xml                 — конфигурация сборки
```

## Подготовка к запуску

Перед запуском необходимо проверить настройки базы данных в src/main/resources/application.properties, параметры агентной среды в src/main/resources/jade.properties, доступность зависимостей из lib и параметры внешних веб-сервисов.

Порядок развёртывания, подготовка схемы БД и интеграционные сценарии требуют отдельной проверки. Успешная сборка и запуск при подготовке этого описания не подтверждались.

## Статус и ограничения

В pom.xml указана версия 0.0.1-SNAPSHOT. Проект следует рассматривать как прототип, а не готовую к промышленной эксплуатации систему.

Приоритетные направления доработки:

- Проверить жизненный цикл поведений OrderCriticalPathAgent: завершение обработчиков, периодическое создание поведений и сравнение conversationId через equals вместо ==.
- Переработать конфигурацию безопасности: убрать тестовую учётную запись, определить правила доступа и пересмотреть отключение CSRF.
- Проверить и обновить зависимости с учётом совместимости JADE и Spring.
- Добавить проверенные инструкции по сборке, настройке базы данных и запуску.
- Расширить автоматические и интеграционные тесты.
- Исключить из контроля версий результаты сборки, кэши и локальные настройки IDE.

Описание подготовлено по статическому анализу структуры и ключевых классов проекта; корректность алгоритмов и интеграций в работающей среде не подтверждена.
